ScannerAz mobile application

Product scope

Research tools designed for sellers

ScannerAz is built for seller-side research. It requests only the Amazon functionality necessary for the features below and does not request buyer, payment, order, tax, or messaging data.

Listing eligibility

Checks whether a seller account can list an item in a requested condition and surfaces listing restrictions that need review.

Catalog matching

Matches a scanned UPC, ASIN, or product name to catalog candidates so the seller can assess the correct product record.

Offer and price review

Shows seller-facing offer and price signals that help a seller decide whether a sourcing opportunity merits further review.

Amazon data access

Minimal requested access

ScannerAz is being prepared as a public application. Each selling partner will authorize their own Amazon connection through OAuth, and their authorization remains isolated from all other accounts.
